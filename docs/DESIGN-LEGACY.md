# Legacy design inventory

QuizMeadow 1.1.1 used a manually adapted personal design version 1.3: green canvas, orange actions, condensed uppercase page headings, optical ring art, per-route media overrides and entrance travel. It had no managed project design pin. Registration at 2.1.0 installs a clean comparison bundle only; it does not assert compliance with that release. Review remains pending until adoption of project system 3.0.1.

Equivalent roles were inventoried across Today, Library, Review, History, results, Settings, setup and the quiz player. History is a collection of whole-item navigation buttons, not a selectable table. No table selection role is used. Existing scoring, persistence, commands and YAML schema are outside the design scope.
